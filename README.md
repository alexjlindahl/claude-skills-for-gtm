# Claude Skills for GTM

Claude skills for go-to-market work: account research, prospecting and sales enablement.

## Skills

| Skill | What it does |
|---|---|
| [Clay Org Chart Builder](skills/clay-org-chart-builder/) | Builds an interactive C-Suite and VP org chart for any company from Clay, with inferred reporting lines, new-in-role badges, recent news and on-click email and mobile lookups. |

## Using a skill

Each skill lives in its own folder under `skills/`, with a `SKILL.md` and any scripts or assets it needs.

- **claude.ai:** download the skill's folder, zip it, and upload the zip as a custom skill in your Claude settings.
- **Claude Code:** copy the skill's folder into `~/.claude/skills/` (or your project's `.claude/skills/`).

Check each skill's README for what it needs, such as which connectors to enable.
