# Claude Skills for GTM

Claude skills for go-to-market work, shared by Alex Lindahl.

| Skill | What it does |
| --- | --- |
| [ics-generator](skills/ics-generator/SKILL.md) | Ideal Customer Signals analysis for any company: maps observable buying signals to messaging, campaigns and detection logic. |
| [clay-org-chart-builder](skills/clay-org-chart-builder/SKILL.md) | Interactive C-Suite and VP org chart for any company, built from Clay, with inferred reporting lines and on-click contact lookups. Needs the Clay connector. |

## Install

Each folder under `skills/` is one skill. Zip the folder so `SKILL.md` sits at the top level of the zip and upload it to Claude as a skill, or copy the folder into `~/.claude/skills/` for Claude Code.
